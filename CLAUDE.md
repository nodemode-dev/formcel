# CLAUDE.md · FormCel

Spreadsheet app in the form family. Read `README.md`, then the `HASHOUT_LOG.md` of the side you touch, before editing.

## Layout

- `engine/` · Rust workspace. `formcel-core` holds every calculation rule; `formcel-wasm` and `formcel-py` only translate calls. A rule written anywhere else is a bug.
- `backend/` · FastAPI engine process on 127.0.0.1:8199. Imports `formcel_engine` (the Python build).
- `frontend/` · TypeScript and Vite window on localhost:5199. The engine runs in `src/engine/worker.ts`; the UI talks to it only through `src/engine/index.ts`.
- `docs/functions.json` · the function catalogue behind autocomplete. Its names must match `FUNCTIONS` in `engine/crates/formcel-core/src/formula.rs` exactly; add a function to both in the same change. It is generated by `tools/catalog/build.py` in the planning sidecar from fetched vendor pages, like a lockfile, and is not edited by hand.

## Commands

```
./formcel_oc_install          install everything
./formcel                     run engine and window
engine/build_wasm             rebuild the window's engine after a Rust change
pip install ../engine/crates/formcel-py   (from backend/, venv active) rebuild the Python engine
cd frontend && npx tsc --noEmit           typecheck
```

## Rules

- Surgical edits only: one region per edit, by hand. No scripted edits, patches or codemods.
- No DOM re-renders, flashes or layout jumps. Patch the node that changed; reserve space first.
- Every z-index is a token from `frontend/src/styles/z-layers.css`.
- No emoji, no icon libraries (inline `currentColor` SVG in `src/ui/icons.ts`), no em dashes in markdown.
- Near-zero comments in code; explanations go in the side's `HASHOUT_LOG.md`.
- Commits as `nodemode-ai <mackin@nodemode.ai>`. Versions read `v` digit dot digit dot digit and match across `frontend/package.json` (and its lockfile), `frontend/src/version.ts`, `backend/app/version.py` and `engine/Cargo.toml`.
- Tests live in `tests/` folders and run in CI; write only tests this plan or its successor names. The plan is `FAMILY_TEST_PLAN.md` in the formai_dev sidecar; `cd backend && python -m pytest tests` runs them (after the engine module is built).

## Linked data types and related features (declined for patent risk, 2026-10-23)

- Linked records (Stocks, Currencies) live in the workbook record store (`engine/crates/formcel-core/src/records.rs`, saved as `records` in the .fcel and as the records list in `formcel/datatypes.json`). A cell holds only the record id and its display label, never the record or any of its fields. Field access (`=A1.Price`), the card, Insert Data, refresh and copy and paste resolve through the store. Text that still carries a whole record is accepted only to move it into the store.
- No per-field show or hide properties on linked records: the card and the cell never keep a visibility flag per field.
- Sparklines have no in-app group edit or ungroup. Group membership is not editable from the window.
- Data Model relationships are always explicit, created by the person. Never infer one from a formula or from names, and never add a relationship because a formula uses RELATED.
- Flash Fill stays a single synthesis pass. No relaxed second pass, and no loops over the examples.
- No action that collapses a range into one cell as an array. Each range stays in its own cells.
- No blur, sharpen or glow image functions driven by cell values.
- Ribbon groups collapse whole. Never move part of a group into an overflow pane.
- These rules are docs only for now and may move into the repository's checks later.

## Trademarks, copyright and licences

- Other vendors' product and feature names appear only to name a file format, a key set or compatibility ("Excel Workbook (.xlsx)", "opens files from"). Never as a FormCel command, menu, panel, tool, ribbon group, preset or agent tool name, and never as "like Excel" or "Excel's" in UI text, READMEs or changelogs. The notice in `README.md` and `NOTICE.md` lists every vendor mark named.
- No Excel or Office brand colours and no "like Excel" theme; the Form family theme and orange accent are the default look.
- Never copy vendor help, tooltip, dialog or documentation text; link to vendor pages instead of quoting them. `docs/functions.json` summaries and every template stay in FormCel's own words.
- Never import or trace vendor icons, and never bundle vendor templates, themes, fonts, sample files or stock images. Test fixtures are generated by our own scripts.
- API compatibility layers (the Office Scripts list) carry names and signatures only, never the vendor's documentation comments.
- Every new dependency, binary, model, font or data file gets a row in `NOTICE.md` before it is used. GPL stays outside the distributed bundle, AGPL nowhere, LGPL dynamically linked and replaceable, MPL files unedited; CC BY credited, CC BY-SA only unmodified, CC NC and ND never.
