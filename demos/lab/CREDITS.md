# Demo credits

Nothing in this demo is third-party media. The Lab measurements workbook is FormCel's own work, built from a fixed seed with FormCel's own engine by `scripts/demo-workbooks.py`; the lab, its four analysts and every reading in it are invented. The page uses the bundle, fonts and window engine stored in `demo/assets`; their components are listed in `demo/CREDITS.md` and `NOTICE.md`.

The app opens the same demo from Home > Demos, Help > Demos and the `demo-lab` command, from the same workbook, so this note covers it too.
